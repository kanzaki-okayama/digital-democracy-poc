# 岡山市議会 デジタル民主主義ダッシュボード (オフライン対応版)

このパッケージは、岡山市議会の議事録データを可視化したダッシュボードを独立した形で実行するためのものです。

## 内容物
- `index.html`: ダッシュボード本体（データは内部に埋め込まれています）
- `lib/`: 実行に必要なライブラリ群 (Tailwind CSS, Chart.js, Vis-network)

## 使い方
1. ZIPファイルを解凍します。
2. `index.html` をブラウザ（Chrome, Edge, Firefox等）で開いてください。

## 注意事項
- デザインに使用しているフォント（Google Fonts）の読み込みにはインターネット接続が必要です。インターネットがない環境でも動作しますが、フォントが標準のものに切り替わります。
- その他のロジックやデータ表示は完全にオフラインで動作します。
